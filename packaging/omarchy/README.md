# Omarchy packaging (OPR)

`sayit-bin/` is the Arch recipe that re-wraps the upstream `.deb` published on
[github.com/ildella/sayit/releases](https://github.com/ildella/sayit/releases).
The `.deb` is self-contained — desktop binary, sidecar, `sayit` CLI,
`sayit-clipboard`, the agent skill and the licence — so the recipe downloads
one asset and extracts it.

Two placeholders are filled at publish time:

- `__SAYIT_VERSION__` — the released version, without the leading `v`.
- `__SAYIT_DEB_SHA256__` — sha256 of `SayIt_<ver>_amd64.deb`, cross-checked
  against the release asset `digest`.

`.omarchy/package.json` describes the upstream to the Omarchy package tooling:
`github: ildella/sayit`, asset `SayIt_{pkgver}_amd64.deb`, `digests: true`.

`.SRCINFO` is generated by `makepkg --printsrcinfo` and is git-ignored; don't
commit it.

## Local test (Arch container)

```sh
docker run --rm -it -v "$PWD/packaging/omarchy/sayit-bin:/pkg" archlinux:latest
# inside:
pacman -Syu --noconfirm base-devel namcap gtk3 webkit2gtk-4.1 libayatana-appindicator nodejs mpv hicolor-icon-theme
useradd -m builder && chown -R builder /pkg
su builder -c 'cd /pkg && makepkg -c && namcap PKGBUILD sayit-bin-*.pkg.tar.zst'
```
